# 成员 3：图片上传、显示与替换

状态：待实现

## 范围

- 每帖一张 JPEG 或 PNG。
- 上传、预览、公开显示和替换。
- 图片元数据写入 `post_images`。
- 通过 PHP 受控读取文件。

## 路由

- `POST /posts/{id}/image`
- `GET /images/{id}`

## 文件与目录

- 文件写入 `storage/baseline_images/`。
- 数据库只保存文件标识和元数据。
- 不把上传目录直接暴露为 Nginx 静态目录。

## 必须交接

- `save_post_image()` 或等价服务接口。
- 图片 ID、帖子 ID、存储标识和 MIME 类型。
- 上传错误码、文件大小和图片尺寸。

## Baseline 缺口

- R01：只检查扩展名。
- R02：直接返回原始文件。
- R04：图片接口只按图片编号查询。
- R09：替换图片先切换或删除旧引用，缺少完整失败回退。
